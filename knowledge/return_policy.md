# Returns and Refunds

Standard, non-personalized items may be returned within 30 days of delivery if unused and in resalable condition. The customer pays return shipping for change-of-mind returns. Northstar Market covers return shipping for confirmed damaged, defective, or incorrectly shipped items. Personalized goods are not eligible for change-of-mind returns after production begins. Approved refunds go to the original payment method; the payment provider controls posting time. Ask for the order number when eligibility depends on a specific purchase.
